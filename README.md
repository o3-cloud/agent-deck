# Agent Deck

A Stream Deck plugin for driving Claude Code sessions running in [Ghostty](https://ghostty.org). It turns a
few physical keys into live-updating slots: launch a session, see its status at a glance, and jump straight
to whichever session needs your attention next.

See [SPEC.md](./SPEC.md) for the design principle behind this (state-driven "slots" rather than fixed-purpose
keys) and the longer-term, agent-agnostic direction.

## Actions

- **Agent Session** — Press once to launch a new Claude Code session in a Ghostty window; the key then shows
  that session's live name and status. Press again to focus its Ghostty window.
- **Session Status** — A read-only dashboard key showing a live count of running sessions grouped by status
  (`waiting`, `busy`, `idle`, `shell`), with the dot color reflecting the most attention-worthy status present.
- **Attention Queue** — A FIFO queue of sessions that have gone idle or are waiting on you. Shows the
  oldest-waiting session's name; pressing it focuses that session's window and pops it off the queue.

## How it works

Session state is read from `~/.claude/sessions/*.json` — one file per live session, keyed by PID, written by
something outside this repo (a Claude Code hook). A session is considered live only while its PID is still
running. Launching and window focus both go through Ghostty's native AppleScript dictionary rather than
`open`/System Events, since Ghostty can have multiple OS processes running and only its own scripting
dictionary can reliably reach every window across all of them.

This makes the plugin Claude Code + Ghostty specific for now (see SPEC.md for the planned agent-agnostic
direction).

## Requirements

- macOS 12+ (Windows is declared in the manifest but Ghostty launch/focus is AppleScript-based, so the
  launcher and focus actions are mac-only today)
- [Stream Deck](https://www.elgato.com/stream-deck) software 7.1+
- [Ghostty](https://ghostty.org) installed
- [Claude Code](https://claude.com/claude-code) CLI on `PATH`, plus whatever writes `~/.claude/sessions/*.json`
  for your setup
- Node.js 24 (bundled with the plugin at runtime via the Stream Deck SDK's Node integration)

## Development

Install dependencies and link the plugin into Stream Deck:

```sh
npm install
npx streamdeck link com.owenzanzal.agent-deck.sdPlugin
```

Build once:

```sh
npm run build
```

Watch and auto-restart the plugin in Stream Deck on every change:

```sh
npm run watch
```

Useful `streamdeck` CLI commands during development:

```sh
npx streamdeck list                            # show linked/installed plugins
npx streamdeck restart com.owenzanzal.agent-deck
npx streamdeck stop com.owenzanzal.agent-deck
```

## Project layout

```
src/
  plugin.ts              entry point — registers the three actions
  actions/                one file per Stream Deck action (UI + key handling)
  session-reader.ts       reads and parses ~/.claude/sessions/*.json
  attention-queue.ts      shared FIFO queue, polled independently of any one button being visible
  launcher.ts             spawns a new Claude Code session in a Ghostty window
  ghostty-focus.ts        focuses an existing Ghostty window by name
  status-icon.ts          renders the SVG status dots/badges used as key images
com.owenzanzal.agent-deck.sdPlugin/
  manifest.json           Stream Deck plugin/action manifest
  bin/plugin.js           build output (generated by rollup, not checked in for edits)
```
